Splash screen — three concepts

F28-T03. The old gradient-and-glow splash is gone; these replace the idea rather than refine it. All three are built from five brand values and carry no text.

The rule every one of them obeys: at t = 0 the screen is flat #0A6C76 with the mark already at full size and full opacity — pixel-identical to the native splash before it. The mark never moves and never fades in. Only the background arrives, and only once.

Why the flicker goes away

The ~440 ms before Flutter draws anything cannot be removed — that is engine and VM startup. So the mark moves into the native splash instead, and Flutter's first frame is built to match it. These two are the same frame:

Nothing changes at the swap, so there is nothing to notice. The logo is present from ~100 ms instead of ~775 ms.
